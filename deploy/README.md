## 运行方式

本机构建 Vite 的两个入口，服务器仅由 Nginx 提供静态文件，不需要常驻 Node 进程或生成 API。首页映射至 `game.html`；游戏内的实验室链接明确指向 `index.html`，与本地开发环境兼容。

| 路径 | 用途 |
| --- | --- |
| `/var/www/frostbound/current` | 指向当前发布版本的符号链接 |
| `/var/www/frostbound/releases/20261102T000638Z` | 完整运行文件及预压缩版本 |
| `/var/www/frostbound/acme` | HTTP-01 证书验证目录 |
| `/etc/nginx/conf.d/game.xqsingular.com.conf` | 独立虚拟主机配置 |
| `/root/frostbound-deploy-backup/20261102T000638Z` | 上传包、SHA-256 清单、原配置快照与原版本指针 |
| `/var/log/nginx/frostbound.access.log` | 访问日志 |
| `/var/log/nginx/frostbound.error.log` | 错误日志 |

66 个当前原始运行文件均已在服务器逐一比对 SHA-256；本次 8 个更新文件通过公网下载并逐个比对。原有站点配置在发布后再次校验，内容未改变。静态文件由 root 拥有、Nginx 只读。上传包及运维资料不在 Web 根目录。

JS/CSS 等散列文件使用长期缓存；HTML 和 JSON 重新验证；其他模型、图片、字体及音乐缓存一小时。适合压缩的文件预生成 gzip，减少服务器实时压缩开销。音频保留字节范围请求支持。

## HTTPS 与续期

使用 Let's Encrypt，当前证书到期日期为 2027-01-30。HTTP 自动跳转 HTTPS，证书验证路径单独放行。证书位于 `/etc/letsencrypt/live/game.xqsingular.com/`；私钥仅留在服务器。

`frostbound-cert-renew.timer` 已设置为每天两次检查，并附加随机错峰时间。客户端复用服务器已安装的 `/opt/3d-model-studio/venv/bin/certbot`；只处理游戏域名证书。成功续期后重载 Nginx。模拟续期已通过（首次访问测试 CA 超时，重试成功）。

```sh
systemctl status frostbound-cert-renew.timer
journalctl -u frostbound-cert-renew.service
/opt/3d-model-studio/venv/bin/certbot renew --cert-name game.xqsingular.com --dry-run --non-interactive --no-random-sleep-on-renew
```

## 后续更新与回退

执行 `npm run build`，将 `dist/` 内容上传至新的 `releases/<版本>/`，验证资源完整性后，使用临时符号链接和 `mv -Tf` 原子替换 `current`。保留之前的发布目录；回退时将 `current` 指回旧版本即可。修改 Nginx 配置时先运行 `nginx -t`，验证通过再 `systemctl reload nginx`。

没有在项目、发布包或网页中保存登录密码。游戏存档使用浏览器 localStorage，因此线上域名与 localhost 的存档独立，切换浏览器也不会自动同步。
