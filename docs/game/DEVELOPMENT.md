# 霜界 · 归墟之门

## 完整目标

从现有技能实验室进入独立、可存档的单机动作 RPG。必须实际游玩验证：探索、清怪、精英、三阶段首领、战利品、装备与成长、死亡恢复、结局和再次挑战。保留原有实验室。

## 美术与素材

- 原创文生图：主菜单世界观插画、16 格道具图集、关键道具概念。
- 3D 生成：沿用已验证的冰弓、冰箭、苍雷剑，并为世界制作新关键资产。
- Mixamo：用户提供的战斗 FBX，加 Three.js 官方 Mixamo 示例的 Idle / Walk / Run，保留原角色贴图。
- 免费场景素材：Quaternius Stylized Nature MegaKit 与 Ultimate Modular Ruins Pack（CC0），包含植被、岩石、雕刻石柱、破损拱门、雕像与地砖；场景布局、道路、水体和光照定制。
- 所有运行素材本地化；记录来源、许可证、生成提示词及优化步骤。

## 可玩结构

三个连通区域：听雪林地、悬星遗迹、归墟王座。玩家从营地出发，解除两处封印，开启王座并击败多阶段首领。区域包含主路线、探索奖励、可恢复营地、宝箱和可读记忆。三个流派改变普攻、能力与成长；闪避无敌窗、清楚的敌人预警、可中断的施法和资源取舍形成战斗决策。

## 本轮战斗与画面修整

- 法相追击复用展示页的 HaloBolts 渲染器：从后方轮盘实际位置发射，48 / 64 / 80 / 96 道随攻击成长增加。命中携带同一套细尾迹、冲击环与七片晶体；目标先死亡则重新索敌，无敌人时停止继续发射。
- 剑客普攻改为远程月牙，剑气、箭矢与修士普攻均自动追踪有效目标。Q / E / R 没有目标时提示且不扣资源。成长影响颜色、辐射亮度和 1–4 路同时攻击。
- Q / E / R 使用各自的运镜，近距离使用较宽取景；移动、闪避和滚轮可退出。植被遮挡消隐跟随当前镜头焦点。镜头与输入系统不因演出慢动作停摆。
- 冰箭尾迹按 0.1 m 实际距离重采样，Q 最长 3.2 m，普攻最长 2.15 m，升级不放大带宽。细芯使用屏幕导数抗锯齿，普攻冰晶使用 HDR 边缘高光参与 Bloom。命中后箭身收束、尾迹在 0.24 秒内向命中点消散。
- E 和剑客普攻复用展示页的 SwordTrail，尾迹由月牙后缘轮廓展开；取消了共用箭矢细带的方案。敌方小弹体及碎片改为带切面高光的晶体材质。
- 冰弓在真实 FBX 的待机、跑动和发射姿态中检查掌心位置和前方轴。生成的引路纹理应用于平滑导航曲线；小地图换为局部地形底图、方向、敌人、宝箱、目标与距离标尺。
- 标题新增三张分层原画，流雾和前景视差；音乐改为古筝、笛子等配器的轻音乐。宝箱开启后显示箱盖内衬和空腔，奖励收取后自然退场。

本轮实机使用正常键鼠释放 Q / E / R，检查法阵发射源、剑气连接、材质与 Shader 日志；角色实际升到二级并选择锋芒后，验证了双路冰箭和双路月牙。开启首个宝箱并检查收取状态，打开地图检查真实地形等高线与障碍标记。普攻视觉检查仅短暂冻结实际渲染帧以便观察，随后恢复；没有修改攻击伤害或敌人属性。远景细线的可见性问题通过 Shader 抗锯齿和受控 HDR 解决。

## 2026-11-01 · 锋芒逐层成长

此前攻击形态在伤害达到基础值的 1.9 倍时封顶，后续锋芒只有数值变化。现在保留四阶主弹道，增加独立的 0–50 层锋芒列阵：每层提供一枚实体冰羽 / 飞剑 / 灵符和每轮一次真实追击。新灵锋形成时单独亮起，原有列阵位置保持稳定。存档读取会直接恢复对应层数；50 层达到原存档上限后不再扣费购买，避免重载丢层。

GameFervorVolley 与 GameFervorVFX 共享世界空间发射位置。每 120 ms 最多发射四枚，持续攻击刷新一轮齐射，避免无界排队。每枚造成当前攻击力 10% 的伤害，每五层增强最后一枚的伤害与实际小范围爆炸。追击不额外消耗灵力。死亡目标自动重新选择；无敌人时取消余下发射；复活清空队列。普通攻击与 Q/E/R 均能触发，主弹道完整伤害保留。

实体使用三套有厚度的倒角轮廓、流动刻线与菲涅耳边光，列阵和飞行头各一份 InstancedMesh；拖尾继续使用实飞历史缓存与接触点收束。所有弹道复用原 96 槽池，灵锋使用 16 号及以后的槽位，留出主攻击位置。命中采用小型晶片爆发，末枚使用强化冲击；普通灵锋命中不会叠加大型辉光球。升级卡、灯台与 HUD 明确展示枚数、每轮追击次数和攻击前后变化。

验证：全量 141 项测试通过，生产构建通过。新增测试实际遍历 1–50 层的发射数、命中数和递增伤害；验证三职业普攻与 Q/E/R、20→21 层跨存档恢复、末段范围伤害、失去目标、复活、敌弹饱和时主技能仍可发射、固定 GPU Buffer 和三个不同厚度轮廓。

## 2026-11-01 · 细针灵锋、长生护罩与灵息法术成长

灵锋从宽片羽刃改为六棱双端收尖的针体；三个流派保留细微粗细差别，长宽比均大于 25。飞行拖尾宽度降至 0.018，保留真实轨迹、物理追击及每层新增单位。
