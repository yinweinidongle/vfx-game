## 觉醒

天刃镇岳消耗 95 灵力、冷却 78 秒。巨刃追踪目标至 0.92 秒后锁定，1.25 秒劈落，2.02 秒余震；伤害分别为施放时攻击与灵息增幅的 8.8 / 3.2 倍。实际范围为中心线长 14 米、半径 4 米的胶囊区域，地面预警使用相同方向、范围。生成的实体长刀参与 PBR 光照，Shader 刻纹、菲涅耳、高光与历史轨迹流光叠加，接触时引发碎片与冲击波。

万象冰劫消耗 100 灵力、冷却 92 秒。领域在 0.75 秒锁定于敌群中心，半径 10.5 米；1.12 秒起每 0.38 秒一次，共八次 1.05 倍伤害，最后一次为 4.8 倍终结。普通/精英/首领冻结分别为 0.6 / 0.3 / 0.16 秒，并通过既有冻结系统控制实际行动。每波提前 0.28 秒锁定领域内敌人的位置，实体冰箭沿世界竖直方向刺下；落地冰爆与半径 2.4 米的局部命中判定使用同一落点，每名敌人每波至多受击一次。后续波次重新索敌。旋转飞散的小冰晶仅在接触后生成。

两项新觉醒复用对应职业已有的高清透明立绘，分别换用金色天刃、青蓝冰劫的全屏暗场、标题、宣言与光带；新增重刃扫频、低频冲击与高频冰晶音效。它们没有新增豆包配音，原 G 的三职业配音保持生效。镜头包含召唤全景、落刃和俯视冰暴，立绘遵循减少动态效果偏好；镜头可取消，低画质关闭后处理 Bloom。

## 强化与修行

强化 `+0…+20`。从当前等级 n 升一级的概率为 `max(12%, 100% − n × 4.6%)`，费用为 `(24 + 装备等级 × 3) × 品质价值 × 1.22^n × (1 + 0.1n)`，取整。品质价值为普通 1、稀有 2.4、史诗 6。失败仅消耗灵石，保留装备与等级；不降级、不销毁。界面在操作前显示实际概率、费用、下一等级属性和结果。

属性倍率为 `品质倍率 × (1 + 0.08n + 0.007n²)`；品质倍率为 1 / 1.7 / 2.8。每一级连续增强边缘 HDR、刻纹与扫描流光，+0 / +5 / +10 / +15 / +20 对应浅蓝 / 蓝 / 紫 / 红 / 金，依靠场景实际 UnrealBloomPass 出辉光。低画质按既有设置关闭后处理 Bloom，材质色阶仍保留。相同外观的附件复用缓存；20 / 35 级或 +8 / +16 强化解锁两次造型进阶。每次强化只更新 Shader 参数，跨外观阶段才切换模型。

商会支持花灵石提升锋芒、长生、灵息，沿用原先每条 50 层成长与对应护罩/灵锋/技能进阶。旧存档自动获得空装备包与新觉醒等级门槛，不重置旧遗物、等级、轮回或修行。

## 资产与实现

见 [EQUIPMENT-ART.md](EQUIPMENT-ART.md)。五件模型由本次 ImageGen 概念图经 Seed3D 生成，并非用基础几何代替。每件运行版约 1 万三角形，五件共约 2.5 MiB；768px WebP PBR 贴图，模型只加载一次，多件复用几何与纹理。护甲的骨骼权重、附件坐标均按真实 FBX 的单位转换到米。

新增模块：GearData、GameGear、GameGearUI、GameGearAppearance、GameLootVFX、GameAscendantVFX。仿真不依赖 DOM；伤害用施放时快照，渲染只消费仿真事件和同一领域锚点。冰爆 80 槽、碎片 640 槽、历史拖尾 28 段，均复用缓冲。生成密钥仅用于离线任务，不进入前端或仓库。
