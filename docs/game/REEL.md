# 游戏特效剪辑

成片：`output/frostbound-gameplay-20s-1080p60.mp4`。实际文件规格与检查结果见 `gameplay-reel.json`。使用真实游戏场景、角色、技能与伤害逻辑的 30 级排演状态，镜头为制作视频重新编排；不读取玩家存档。

## 镜头

| 时间 | 内容 |
| --- | --- |
| 0–4.5 s | 弓手连续普攻、Q 曲线追踪、冰晶命中 |
| 4.5–9 s | 剑客普攻、E 月牙剑气、后续追击 |
| 9–15 s | 低角度法相显圣、法阵齐射、俯拍陨星 |
| 15–20 s | G 高清立绘、豆包短台词、四轮全场落雷 |

法相与觉醒使用适度慢镜；所有画面以 1/60 秒固定步长输出，避免录屏掉帧。法相与落雷来自正式游戏 Shader，立绘是原有透明原画在输出画布中合成。画面帧率不代表设备实战性能。

## 重新导出

1. `npm install` 后启动 `npm run dev`。
2. 另一个终端执行 `node scripts/reel-receiver.mjs`。接收器仅监听本机，录制结束后可停止。
3. 在浏览器打开 `http://127.0.0.1:5173/tools/reel.html`，选择“导出四段成片”。
4. 完成后执行 `python3 scripts/finish-game-reel.py`，需要本机安装 FFmpeg / FFprobe。

中间文件保存在 `output/reel-source/`。成片采用 H.264 / AAC、1080p60、faststart，两遍压缩。脚本检查 1200 帧、20 秒、分辨率、完整解码与文件小于 20,000,000 字节。游戏音效按实际事件时刻同步导出；背景音乐沿用已有 Lotus Pond，觉醒台词期间自动降低配乐。

录制工作台、本机接收器和中间文件不进入正式站点构建。

## 最终成片检查

20.000 秒，1920×1080，60 fps，共 1200 帧；H.264 High / yuv420p，AAC 48 kHz 双声道。文件为 17,396,080 字节（17.40 MB），低于 20 MB。全片解码通过，未检出黑场；9.0–9.4 秒为法相段的短暂建立镜头，随后进入升镜与齐射。压缩相对原始导出 SSIM 为 0.971540，综合响度 −16.7 LUFS，真峰值 −1.4 dBFS。检查记录与逐秒缩略图分别见 `gameplay-reel-qa.log`、`gameplay-reel-contact-sheet.jpg`。
